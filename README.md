# 컷 밖의 밤

기존 프로토타입의 검증된 실시간 시뮬레이션을 선별 이식하고, 화면과 조작을 새로 설계하는 독립 프로젝트다.

## 시나리오

웹툰 원고 마감에 쫓기던 주인공은 손상된 최종 원고를 들고 사옥 지하 원고 보관실로 도망친다. 계속된 야근에서 발생한 '야근 전염병'은 편집팀을 좀비로 만들었고, 이 감염 상태를 '마감 감염'이라고 부른다. 감염된 편집팀은 "작가님, 잠깐만요"를 반복하며 원고를 찾아 쫓아온다. 편집팀은 악당이 아니라 마감 시스템에 잠식된 피해자이며, 주인공의 목적은 이들을 죽이는 것이 아니라 따돌리고 지하 업로드 단말기에서 마지막 원고를 송고하는 것이다.

어둠 속에는 편집팀과 별개로 검은 분신이 돌아다닌다. 검은 분신은 주인공이 버린 콘티와 미완성 선택이 뭉쳐진 존재다. 세계는 진지한 호러로 유지하되, 업무 문구와 주인공의 건조한 반응에서 블랙코미디가 새어 나오게 한다.

기존 프로토타입은 참고용으로 분리 보존하며 이 프로젝트에서 수정하지 않는다.

## 실행

```bash
npm run dev
npm run check
npm run contentcheck
npm run rttest
npm run build
```

로컬 개발 주소는 `http://localhost:3838`이다.

교정 원고형 전투는 `http://localhost:3838/?scene=editor`, 알림 청각형 전투는 `http://localhost:3838/?scene=listener`, 검은 분신 전투는 `http://localhost:3838/?scene=shadow`에서 바로 검수할 수 있다.

## 조작

- `WASD`: 걷기
- `Shift + WASD`: 달리기
- `C`: 원고 선반 옆에서 숨기/해제. 깨어 있는 편집팀의 정면에서는 즉시 발각
- `Space`: 장애물 파괴 또는 후방·동면 편집팀 처리. 은신 중에는 길게 눌러 숨 참기
- `Q`: 알림이 쏟아지는 업무폰 설치
- `B / J / H`: 가방 / 기록 / 조작 패널
- 감염된 편집팀과 접촉한 뒤 `1 / 2 / 3 / 4`: 공격 / 밀치기 / 업무폰 / 도주
- 공격 부위 선택 중 `1 / 2 / 3 / 4`: 머리 / 팔 / 다리 / 몸통
- 적 공격 예고 중 `Space`: 일반 구간에서는 방어, 노란 구간에서는 패링과 반격

접촉 전투 중에는 필드 시간이 멈춘다. 모든 부위 공격은 적의 공용 HP를 깎으며, 팔은 붙잡기를 봉쇄하고 다리는 확정 도주 조건을 만든다. 밀치기도 한 턴의 도주 틈을 만든다.

## 이식 정책

- `engine/`: `player`, `walker`, `listener`, `shadow` 같은 중립 역할과 실시간 시뮬레이션·전투 규칙만 보유
- `maps/`, `balance.json`: 데이터 기반 맵과 수치 밸런스. 캐릭터 표시명과 이미지 경로를 넣지 않는다
- `content/gameContent.ts`: 주인공 표시명, 캐릭터 이미지, 적 이름과 추적 문구의 유일한 진입점
- `app/`, `components/`: 콘텐츠 설정을 화면에 조합하는 입력·표현 계층
- `tests/`: 이식 후에도 지켜야 하는 게임 규칙 계약

엔진과 규칙 테스트는 콘텐츠 모듈을 직접 참조하지 않는다. 다른 캐릭터 IP로 교체할 때는 `content/gameContent.ts`와 `public/assets`만 바꾸는 것을 원칙으로 한다.

## 아트 정책

이번 수직 슬라이스는 별도로 관리하는 캐릭터 라이브러리의 게임용 투명 PNG 가운데 필요한 자산만 선별해 사용한다. 원본 참고 프레임이나 출처 확인이 필요한 파일은 사용하지 않는다.

- 주인공: 라이브러리의 방향별·표정 자산
- 검은 분신: 주인공의 실루엣을 기준으로 만든 프로젝트 전용 파생 시안
- 마감 감염 편집팀: 주인공과 같은 굵은 선·평면 채색으로 통일하고, 교정 원고형과 알림 청각형으로 실루엣을 분리한 프로젝트 전용 아트
- 화면 팔레트: 흑백 종이색 + 위험 상황에만 탁한 적색

검은 분신을 포함한 캐릭터 변형과 외부 배포 범위는 실제 배포 전에 자산 사용 권한을 확인한다.
